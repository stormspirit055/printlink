# PrintLink UI Design System v0.1

本规范从现有“工业制造网络”视觉语言中提炼，目标是让界面在保持辨识度的同时，具备一致、可访问、可扩展的工程基础。代码中的唯一事实来源是 `apps/web/src/styles/tokens.css`。

## 1. 设计原则

- **工作优先**：信息密度适中，操作路径短，不使用营销式大卡片和装饰性堆叠。
- **语义优先**：组件只引用 `canvas`、`surface`、`text-muted`、`primary` 等角色，不直接引用色值。
- **双主题同等可用**：深色是品牌默认，浅色不是反色版本；两套主题分别保证文本、边框和状态对比度。
- **渐进迁移**：旧变量只作为兼容别名。新代码必须使用设计令牌或 Tailwind 的语义类。
- **可访问默认**：320 px 起无横向溢出，键盘可达，焦点清晰，正文对比度以 WCAG AA 为底线。

## 2. 品牌色与语义色

主色为制造绿。深色主题主色 `#4BE0A0`，浅色主题主色 `#18A66F`。主色用于主操作、当前状态、焦点和少量关键指标，不用于大面积背景。

| 角色 | 用途 | 深色 | 浅色 |
| --- | --- | --- | --- |
| `canvas` | 页面底色 | `#0B0E0F` | `#F3F6F4` |
| `surface` | 面板、弹窗 | `#111617` | `#FFFFFF` |
| `surface-raised` | 悬浮、次级分区 | `#161D1E` | `#E8EEEB` |
| `text` | 标题、正文 | `#E8F0ED` | `#17201D` |
| `text-muted` | 辅助信息 | `#8D9B98` | `#66736E` |
| `primary` | 主操作、选中 | `#4BE0A0` | `#18A66F` |
| `info / warning / danger` | 状态反馈 | 蓝 / 黄 / 红 | 对比度增强版本 |

禁止在业务组件内新增十六进制颜色。确需新增角色时，先加入令牌并补齐双主题。

## 3. 字体与排版

中文与 UI 使用系统无衬线字体栈；编号、尺寸、状态码使用等宽字体。禁止通过视口宽度缩放字号，字距固定为 `0`，品牌英文小字除外。

| 层级 | 字号 / 行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| Display | 28 / 35 px | 700 | 页面唯一主标题 |
| H1 | 24 / 30 px | 700 | 页面标题 |
| H2 | 20 / 28 px | 600 | 区块标题、弹窗标题 |
| H3 | 18 / 25 px | 600 | 面板标题 |
| Body | 14 / 21 px | 400 | 默认正文、表格 |
| Body strong | 14 / 21 px | 600 | 重点正文、按钮 |
| Caption | 12 / 18 px | 400/500 | 标签、辅助说明 |

正文不使用 `800/900`；仅品牌标识允许更重字重。中文长文本使用 1.7 行高。

## 4. 尺寸、间距与布局

- 基础间距为 4 px，常用序列：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48`。
- 默认控件高度 40 px，紧凑控件 32 px，大控件 48 px；触摸目标不小于 40 px。
- 圆角序列为 `2 / 3 / 6 / 8 px`。业务面板默认 6 px，弹窗最大 8 px，不使用胶囊形容器承载普通文本。
- 内容最大宽度 1440 px；桌面页边距 24 px，移动端 16 px。
- 页面区块保持无框布局；卡片仅用于重复条目、弹窗和有明确边界的工具，不嵌套卡片。

## 5. 组件规则

- **按钮**：同一区域只有一个主按钮。危险操作默认克制，在 hover/focus 时强化危险色。
- **字段**：标签永远可见；错误信息紧邻字段；placeholder 不是标签；禁用与只读需视觉区分。
- **图标**：统一使用 `lucide-vue-next`。熟悉动作优先图标按钮，并提供 `title` 或 `aria-label`。
- **弹窗**：最大高度 92vh，内部滚动；支持 Escape、背景点击、关闭按钮与焦点恢复；遮罩 10 px 模糊。
- **状态**：不能只靠颜色表达，必须同时有文本、图标或形状差异。
- **空态/加载/错误**：共享组件必须覆盖三种状态，避免业务页临时拼装。

## 6. 动效

- 快速反馈 150 ms，常规组件 200 ms，大视图最多 300 ms。
- 进入使用 `cubic-bezier(.16, 1, .3, 1)`，退出使用 `ease-in`。
- 只动画颜色、透明度、阴影与 `transform`，禁止造成布局抖动。
- `prefers-reduced-motion` 下令牌自动缩短为 1 ms，功能不能依赖动画完成。

## 7. 工程约束

- Vue 3 SFC + `<script setup lang="ts">` + Composition API。
- Tailwind CSS 只使用语义色和标准尺度；禁止任意色值类与随意 `rounded-[…]`。
- 基础控件放在 `apps/web/src/components/ui/`。兼容层可保留旧 API，但新页面不得继续引入 `n-*` 命名。
- 页面不得定义新的全局视觉变量；设计令牌改动必须说明语义与双主题值。
- 每次 UI 变更必须运行 `npm run typecheck -w @printlink/web` 与 `npm run build -w @printlink/web`，并在 320/768/1440 px 宽度下检查明暗主题。

## 8. 初版迁移顺序

1. 令牌与主题基础（本版已完成）。
2. Button、Field、Select、Checkbox、Badge、Modal 等共享 SFC。
3. 应用框架、导航与账号菜单。
4. 需求大厅、详情、订单与消息等业务页面。
5. 删除 `public/styles.css` 中的兼容样式和旧变量别名。
